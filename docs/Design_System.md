# 映像风格的共用界面

语音、登录/注册、个人资料、连接设置、个人收藏、聊天记录、长期记忆和视频使用同一套主题。延续视频工作室已确认的暖白、墨黑、低饱和橄榄色与杂志式留白。

## 实现

- `lib/core/theme/app_theme.dart`：共享浅色/深色调色板、AppBar、输入框、按钮、弹层、对话框与卡片。
- `lib/core/theme/editorial_widgets.dart`：宋体标题、小号英文标识与细边面板。
- `lib/app.dart`：全局使用同一套主题。视频和历史页保留原组件接口，底层复用共享样式。
- `assets/fonts/StudioSerif-Regular.ttf`：OFL 授权的静态宋体子集，仅用于固定标题。用户昵称、消息与记忆内容使用系统无衬线字体，支持任意字符与复制选择。

页面使用 24px 主边距、细分隔线、6–10px 圆角以及清楚的标题/正文/辅助信息层级。主按钮用墨黑/暖白反转适配深色；状态与破坏性操作保留语义颜色。

## 页面调整

- 语音：简洁欢迎区、宋体问候、克制的麦克风标识、中性消息气泡与清晰的底部语音/文字操作区；偏好弹层采用同套控件。
- 用户：登录、注册、验证码、头像、个人主页、资料编辑和设置统一。头像使用细边框，长邮箱与大字体表单可滚动。
- 对话与记忆：收藏入口、聊天日历、对话详情、记忆列表、详情、编辑和变更历史共用编辑式标题、统一卡片和时间标识。

录音、唤醒、播放、取消、会话恢复、登录存储、资料更新、记忆增删改和分页继续使用现有业务实现。没有修改控制器、认证、接口请求或后端契约。
