# 映像风格的共用界面

语音、登录/注册、个人资料、连接设置、个人收藏、聊天记录、长期记忆和视频使用同一套主题。延续视频工作室已确认的暖白、墨黑、低饱和橄榄色与杂志式留白。

## 实现

- `lib/core/theme/app_theme.dart`：共享浅色/深色调色板、AppBar、输入框、按钮、弹层、对话框与卡片。
- `lib/core/theme/editorial_widgets.dart`：宋体标题、小号英文标识与细边面板。
- `EditorialLayout`：共享内容限宽并允许弹层按内容收缩；视频和对话保留原布局入口，个人主页、编辑及设置复用同一约束。
- `lib/app.dart`：全局使用同一套主题。视频和历史页保留原组件接口，底层复用共享样式。
- `assets/fonts/StudioSerif-Regular.ttf`：OFL 授权的静态宋体子集，仅用于固定标题。用户昵称、消息与记忆内容使用系统无衬线字体，支持任意字符与复制选择。

页面使用 24px 主边距、细分隔线、6–10px 圆角以及清楚的标题/正文/辅助信息层级。主按钮用墨黑/暖白反转适配深色；状态与破坏性操作保留语义颜色。

## 图标语言

- 继续使用 Flutter 自带的 Material 图标，不为普通操作引入远程字体或另一套图标包。小图标通常显示为 18–24 逻辑像素，独立图标按钮保留至少 48×48 的点击区域和明确的 Tooltip。
- 语音操作用麦克风，音色用波形；长期记忆用书签，对话归档用翻开的书，视频创作用场记板，图片集合用相册。相同含义在入口、列表、详情和状态说明中沿用同一图形。
- 次要操作优先线性图标，选中状态和主操作可使用实心图标。错误、停止与删除继续使用语义颜色和文字说明；不以星芒等装饰图标代替业务含义。
- 图标服务于页面内容和操作，不增加外圈、渐变或额外卡片来突出普通导航。具体选择仍以页面排版、深浅色、320px 宽度和 200% 文字缩放下的效果为准。

## 页面调整

- 语音：简洁欢迎区、宋体问候、克制的麦克风标识、中性消息气泡与清晰的底部语音/文字操作区；偏好弹层采用同套控件。
- 用户：登录、注册、验证码、头像、个人主页、资料编辑和设置统一。头像使用细边框，长邮箱与大字体表单可滚动。
- 对话与记忆：收藏入口、聊天日历、对话详情、记忆列表、详情、编辑和变更历史共用编辑式标题、统一卡片和时间标识。

录音、唤醒、播放、取消、会话恢复、登录存储、资料更新、记忆增删改和分页继续使用现有业务实现。没有修改控制器、认证、接口请求或后端契约。

## 验证

```sh
flutter analyze
flutter test
```

`test/features/editorial_layout_test.dart` 覆盖 320px、200% 字体下的浅色/深色账户表单；现有语音、记忆和聊天记录测试继续覆盖滚动位置、字幕、取消、音频交接、分页与写入确认等行为。

`integration_test/editorial_ui_test.dart` 和 `test_driver/editorial_ui_test.dart` 使用手机安全登录态读取真实个人资料、聊天记录和记忆。语音截图展示受控的待机/对话状态，不创建真实语音会话；不会更新资料、编辑/删除记忆或发送验证码。截图与结果位于 `build/editorial-ui-verification/`。测试包必须覆盖安装且保留应用数据，完成后恢复 `lib/main.dart` 正常入口。

验收记录（2026-10-23）：静态检查通过，101 项自动化测试通过。USB 真机使用真实个人资料、聊天记录和记忆完成页面截图核对；语音待机、对话与偏好使用受控状态预览，未创建网络语音会话，也未写入个人资料或记忆。截图覆盖登录、资料、编辑、收藏、聊天记录、记忆详情/编辑/历史，以及浅色/深色页面。
